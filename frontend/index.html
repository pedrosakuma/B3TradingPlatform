B3TradingPlatform bootstrap

Participant-side platform in the B3 ecosystem family. This page is a placeholder; the real trader UI ships in a follow-up issue.

Talk to the backend (default http://localhost:5000):

  • GET /health — liveness
  • GET /orders?login=alice — list working orders
  • POST /orders — submit an order
  • GET /positions?login=alice — positions
